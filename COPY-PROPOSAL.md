## The angle: turning "LMS operations" into design evidence

The committee's one doubt: *she clearly runs Canvas well, but can she design learning?* Her work already contains design decisions; the copy just describes them as tasks. The fix is to name the decision and who it helped, not the tool:

| Operations wording (reads as admin) | Design wording (reads as instructional design) |
|---|---|
| built / maintained course sites | designed a consistent course structure |
| checklist, settings, standards | quality standards that set what every course must include before students arrive |
| migrated content into a template | moved existing courses into a shared design without losing faculty content |
| fixed accessibility issues | designed a review process so accessibility is built in, not cleaned up |
| trained faculty on tools | consulted with faculty on course design and trained them to maintain it |

Rule of thumb: every project should answer **what did students experience differently because of this?**
